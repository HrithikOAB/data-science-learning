# data-science-learning

Teaching notebooks and datasets for learning data science with Python.

## Contents

- `Complete_Data_Science_Course.ipynb`: End-to-end data science workflow with a student performance dataset.
- `Data_Cleaning_and_Preprocessing_Course.ipynb`: Missing values, outliers, encoding, scaling, and preprocessing pipelines.
- `Important_Data_Science_Topics.ipynb`: Statistics, sampling, leakage, evaluation, feature importance, ethics, and project checklists.
- `LangChain_RAG_Pipeline_with_100_Page_PDF.ipynb`: Step-by-step RAG pipeline using LangChain and a 100-page PDF workflow.
- `student_performance_test_dataset.csv`: Test dataset used by the data science notebooks.
